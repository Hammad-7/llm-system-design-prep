How to use this list
  1. Pick a prompt in your interview's family that you haven't studied.
  2. Run the Delivery Framework out loud in 45 minutes, drawing as you go.
  3. Grade yourself with the checklist below, then look up the concepts you missed.
  4. Repeat the same prompt a week later. The second attempt is where the learning shows.

Self-grading checklist

AreaStrong signal
RequirementsThree crisp functional requirements; quantified latency, cost, quality and safety targets; scope cut out loud.
EstimationTokens per request, requests per second, and the one derived number that drives the design (GPUs, cost/day, KV memory).
APIStreaming or async job shape chosen deliberately; idempotency; user from auth.
High-level designEvery functional requirement satisfied by minute ~25; model boundary clear; authorization in code.
Deep divesTwo or three, each with an explicit trade-off and a failure mode; at least one quantified.
QualityOffline eval set, metrics, release gate, online signals.
SafetyInjection, data leakage, excessive agency, abuse each addressed where relevant.
CommunicationAssumptions stated, interviewer's probes followed, a crisp summary at the end.

Follow-up questions interviewers love

Have a one-minute answer ready for each. They show up as probes in almost any prompt.

  • Your model provider has a 30-minute outage. What happens?
  • Cost doubled last month. How do you find out why, and what do you change first?
  • A customer reports the assistant showed them another customer's data. Walk through how that could happen.
  • Yesterday's prompt change made answers worse, and nobody noticed for a week. What would have caught it?
  • We're switching to a new model version. How do you roll it out?
  • Traffic grows 10×. What breaks first?
  • Would you fine-tune here? What would convince you?
  • How would you know whether the reranker is worth its latency?
  • A web page the agent reads contains instructions to email the user's files somewhere. What stops it?
  • How many concurrent conversations can one GPU server handle for this model? Show the math.
