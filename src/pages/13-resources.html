Resources & Reading

The primary sources behind this guide, grouped by what they'll help you answer. If you only read five, read the starred ones.

Interview guides and question reports

  • ★ Hello Interview: System Design in a Hurry: the classic system design foundation this guide's structure follows, plus its ChatGPT breakdown and vector databases deep dive.
  • Aced (formerly Exponent): Anthropic system design interview guide: reported questions, including inference batching and file distribution.
  • DesignGurus: What to expect in the OpenAI system design interview.
  • IGotAnOffer: Generative AI system design interview: real questions by company and evaluation criteria.
  • AI Engineering Field Guide: AI system design questions: a list compiled from public interview reports, with sources.
  • KDnuggets: How to answer AI system design interview questions: a reusable framework and reference architectures.
  • PracHub: OpenAI system design questions and Anthropic system design questions.

Agents and context

  • ★ Anthropic: Building effective agents: workflows vs agents and the five workflow patterns.
  • Anthropic: Effective context engineering for AI agents: compaction, notes, sub-agents.
  • Anthropic: How we built our multi-agent research system: orchestrator-workers in production, token economics, evaluation.
  • Anthropic: Writing effective tools for agents: tool granularity, descriptions, token-efficient outputs, evaluating tools.
  • Anthropic: Equipping agents for the real world with Agent Skills: progressive disclosure of procedural knowledge.
  • Cognition: Don't Build Multi-Agents: the counter-argument on context sharing; read it next to Anthropic's multi-agent post.
  • Model Context Protocol: specification and the 2026-07-28 stateless release.

Agent harnesses and coding agents

  • ★ Anthropic: Building agents with the Claude Agent SDK: the gather context → act → verify loop behind Claude Code. Pairs with the Design Claude Code breakdown.
  • Anthropic: Claude Code sandboxing: filesystem and network isolation instead of permission prompts.
  • Claude Code documentation: memory files, permissions, hooks, subagents, MCP, headless mode.
  • OpenAI Codex: agent approvals and security: the same problem solved with Seatbelt, bubblewrap and seccomp.
  • GitHub: How Copilot understands your code and Cursor: online RL for Tab: inline completion in production.
  • SWE-bench Verified and Terminal-Bench: how coding agents are benchmarked.

Retrieval

  • ★ Anthropic: Introducing Contextual Retrieval: hybrid search, reranking, measured failure-rate reductions.
  • Lost in the Middle: How Language Models Use Long Contexts: why more context isn't automatically better.
  • Ragas documentation: RAG evaluation metrics.
  • HNSW (Malkov & Yashunin) and Faiss: guidelines to choose an index: the vector-index trade-offs in Embeddings & Vector Search.
  • GraphRAG (Microsoft): when entity graphs beat chunk retrieval, and what they cost.

Context, memory and evaluation

  • ★ Anthropic: Effective context engineering and Chroma: Context Rot: why bigger windows don't remove the need to curate.
  • MemGPT and Mem0: long-term memory architectures.
  • Judging LLM-as-a-Judge (Zheng et al.): judge biases and how to measure agreement.
  • Anthropic: A statistical approach to model evaluations: confidence intervals for eval scores.
  • Hamel Husain: Your AI product needs evals: the practitioner's version of the eval flywheel.
  • OpenTelemetry GenAI semantic conventions: a vendor-neutral schema for LLM traces.

Inference and serving

  • ★ Efficient Memory Management for LLM Serving with PagedAttention (vLLM): KV cache, batching, why memory caps throughput.
  • Orca: iteration-level scheduling (OSDI 2022): the origin of continuous batching.
  • Fast Inference from Transformers via Speculative Decoding.
  • DistServe and Mooncake: prefill/decode disaggregation and KV-centric serving.
  • SGLang (RadixAttention): prefix sharing as a radix tree, the basis of engine-level prompt caching.
  • LoRA, QLoRA and DPO: the three fine-tuning papers worth knowing, covered in Fine-tuning & Adaptation.
  • vLLM, SGLang and llm-d on GitHub.

Security and safety

  • ★ OWASP Top 10 for LLM Applications.

  • Design Patterns for Securing LLM Agents against Prompt Injections and CaMeL: architectural defenses rather than filters.
  • OWASP GenAI Security Project: the LLM Top 10 and the agentic risk list.
