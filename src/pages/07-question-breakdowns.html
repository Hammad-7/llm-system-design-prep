LLM System Design · Fast Track

Question Breakdowns

Complete walkthroughs of the most common LLM system design prompts, following the delivery framework from requirements to deep dives, with what's expected at each level.

Each breakdown is written the way a strong candidate would run the interview: requirements first, then entities and API, then a high-level design built one requirement at a time, then deep dives. In the deep dives you'll see three options for each problem:

  • Bad Solution what many candidates propose first, and why it breaks.
  • Good Solution a solid answer that passes at mid-level.
  • Great Solution what senior and staff candidates reach, usually by quantifying or by handling failure modes.

Pick the breakdown closest to your interview type and try it cold first (see How to Prepare).

LLM product · Medium

Design ChatGPT

Streaming chat at consumer scale: conversation state, resumable streams, context management, GPU admission control.

 Retrieval · Medium

Customer-Support RAG Assistant

Grounded answers with citations, permission-aware retrieval, safe actions, freshness and evaluation.

 Infrastructure · Hard

Inference Batching Service

The most-reported frontier-lab prompt: batch formation, routing responses back, GPU failover, overload, continuous batching.

 Agentic · Hard

AI Coding Agent

Issue in, pull request out: sandboxes, codebase context, durable long runs, injection and secret safety, agent evals.

 Agent harness · Hard

Design Claude Code

A coding agent in the terminal: the agent loop, tools, permissions and OS sandboxing, context compaction, hooks, MCP and sub-agents.

 Latency-critical · Hard

Copilot-style Autocomplete

Ghost-text completions in a few hundred milliseconds: fill-in-the-middle prompts, context selection, cancellation, small models.

 Retrieval · Hard

Perplexity-style Answer Engine

Web search, fetch and synthesis with citations under a tight latency budget, freshness and source quality.

 Multi-agent · Hard

Deep Research Agent

A lead agent and parallel sub-agents that research for minutes and write a cited report; cost, durability and evals.

 Platform · Medium

LLM Gateway

One front door for every team's model traffic: quotas, routing, fallbacks, streaming proxy, cost attribution.

 Real-time · Hard

Real-time Voice Agent

Sub-second voice-to-voice: STT, LLM and TTS streaming, turn detection, barge-in, telephony and evals.

 Pipeline · Medium

Document Extraction Pipeline

Payslips, IDs and invoices in, validated structured data out: OCR vs vision models, review queues, cost per document.

 Internal search · Medium

Internal Repo Discovery

Natural-language search over every company repo with owners and contact: GitHub App sync, webhooks, AI enrichment, cache invalidation.
